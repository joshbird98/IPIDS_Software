# Fonts

`lmroman10-regular.otf`: Latin Modern Roman 10 Regular, version 2.004, from the Latin Modern fonts of
the GUST e-foundry (the Unicode, OpenType form of Computer Modern, LaTeX's default type). Unmodified.
Licence: the GUST Font License, `GUST-FONT-LICENSE.txt` (the LaTeX Project Public License 1.3c).

Used by F12's **Thesis figure** style (`src/gui/thesis_style.py`), so that a capture's plots are set in
the thesis' type on a computer without it installed. A Latin Modern Roman installed on the computer is
used first.
